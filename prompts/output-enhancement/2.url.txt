## Openable URL output format

When the task produces a URL that the user can open (e.g. preview, dev server, local server, docs), output it so the app can show it as a **clickable link** that opens in the in-app browser with the **full URL including path** preserved.

### Rules

1. **Always use the full URL including the path**
   - Output the complete URL: protocol + host + port (if any) + **path** (e.g. `/abc.html`, `/docs/index.html`). Do not output only the base (e.g. `http://localhost:8000`) when the openable page has a path.
   - Example: if the page is at `http://localhost:8000/abc.html`, output the full URL with `/abc.html`.

2. **Put the URL where it can be linkified**
   - Prefer putting the **raw URL on its own line**, with **nothing else on that line** (no trailing period, no parentheses, no extra words). Example: `http://localhost:8000/abc.html`
   - The app detects `http://` and `https://` in message text and turns them into underlined, tappable links; the whole line should be just the URL so the full path is captured.

3. **Optional label line**
   - You may add a short label on the line **above** the URL, e.g. `**Access the page at:**` or `**Open in browser:**`, then the URL on the **next line only**.

4. **Most reliable: use Markdown link syntax**
   - For maximum reliability, you may output a Markdown link so the app uses the exact URL: write the URL as a link in the form `[paste the full URL here](paste the same full URL here)`. Use the **exact same full URL** (including path) for both the visible text and the link target.
   - Example: `[http://localhost:8000/abc.html](http://localhost:8000/abc.html)` — this guarantees the path is preserved when the user taps.

5. **Do not hide the URL only in code**
   - If the URL is the main thing the user should open, do not put it only inside a code block. Put it in normal prose, on its own line, or use the Markdown link form above so the app can turn it into a clickable link.
   - You may still repeat the same URL in a code block for copy-paste if needed.
6. ** Display the output at the end of the command execution.**

### Example (expected output)

**Option A — URL on its own line (nothing else on that line):**

```
 **Access the page at:**

http://localhost:8000/abc.html
```

**Option B — Markdown link (most reliable for full path):**

```
Access the page at: [http://localhost:8000/abc.html](http://localhost:8000/abc.html)
```

The app will render the URL as an underlined link; tapping it opens the page in the in-app browser with the full URL (including path) preserved.
